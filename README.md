# CostaHogar — Portal de Inmuebles en Venezuela

Prototipo de portal web de venta/alquiler de inmuebles en Venezuela, con foco inicial
en Isla de Margarita, inspirado en Idealista (España).

Nace como evolución de los grupos de Facebook "Ventas Inmuebles Isla de Margarita"
y "Ventas Inmuebles Venezuela".
